4. How to Use

Import the package into your Unity project.

Open the demo scenes to preview characters and skill effects:

Character Demo: Assets/RAD_Pixel2D_Characters_Wizard/Demo/Demo_CharScene.unity

Skill Demo: Assets/RAD_Pixel2D_Characters_Wizard/Demo/Demo_SkillScene.unity

Drag & drop character prefabs and skill effect prefabs from the Prefabs folder into your scene:

Assets/RAD_Pixel2D_Characters_Wizard/Prefabs/

Play the scene to verify animation playback.

5. Recommended Import Settings (Pixel Art)

Pixels Per Unit (PPU): 64

Filter Mode: Point (no filter)

Mip Maps: Off (recommended for pixel art)

Compression: None (recommended for crisp pixel art)

6. Sprite / Pivot Details

Sprite slicing: All sprites are sliced using Automatic (not “Grid by Cell Size”), and frame sizes/pivot positions were manually adjusted.

Characters: All character sprites use a consistent pivot aligned to the feet (ground/shadow line).

Skill Effects: Skill effect pivots are set to either the center or the bottom depending on the effect.

Idle/Walk production size: Character Idle/Walk animations were created in a 64×64 or larger working frame size.

Projectile prefabs (`*_Arrow`)

- The projectile “in-flight” state is based on the Idle animation.

- These prefabs were created under the assumption that the Hit animation will play when the projectile collides with a target.
